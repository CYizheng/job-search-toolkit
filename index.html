为什么是零依赖

这两类工具的生命周期通常只有几个月。装依赖的摩擦——venv、pip 源、版本冲突——比功能本身更容易让人放弃。 所以台账只用 argparse / json / sqlite3 / http.server；面试器只用浏览器原生 API， 连构建步骤都没有，改完刷新即可。
